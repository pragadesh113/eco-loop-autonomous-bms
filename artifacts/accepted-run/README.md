# Accepted Compact Run

These compact files summarize immutable local run
`controlled-run001-optimized-v3` against `baseline-sim002-isolated-a`.

- `summary.json`: controlled energy, comfort, decision, and reliability metrics.
- `comparison.csv`: exact baseline-versus-controlled judging values.
- `session-result.json`: terminal EnergyPlus lifecycle counts.
- `audit-summary.json`: compact safety and graph/MCP lifecycle evidence.
- `../dashboard-accepted-run.png`: rendered accepted/rehearsal dashboard evidence.

Large raw EnergyPlus and JSONL outputs remain under ignored
`runs/controlled-run001-optimized-v3/`. Their hashes and independent verification are
recorded in `evidence/run001/verification.v1.json`.
